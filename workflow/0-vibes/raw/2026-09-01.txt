## Как это началось

Пользователь прислал файлы с IP/root/паролем чужого сервера и ссылками на
референсный проект `queue-assignment` (MCP-сервис электронной очереди на
Laravel 12) + видео на Яндекс.Диске "как это работает". Запрос: "Как сделать
свой MCP, как в образце?"

Отказ использовать чужие SSH-доступы/токен коннектора — похоже на доступ к
чужой системе. Уточнение задачи: нужен СВОЙ аналог, не подключение к чужому.

## Первая итерация — Python

Собран рабочий прототип: FastAPI + SQLite + официальный MCP SDK, REST API +
6 MCP-инструментов для задач. Проверен локально.

## Пивот — на Laravel, локально в OSPanel

Пользователь уточнил: нужно на Laravel, там, где он уже начал
(`J:\OSPanel\home\task-treker.local`). Тема сменилась с "очередь" на
"таск-трекер" ("допустим таск трекер").

## Факты (проверено по коду)

- Laravel 12, PHP 8.2+ (прод — PHP 8.5), Sanctum для REST-токенов,
  собственный JSON-RPC MCP-эндпоинт (без внешних MCP-пакетов).
- Два независимых типа токенов: Sanctum `access_token` (REST) и `McpToken`
  (MCP) — сознательное архитектурное решение, не смешивать.
- UI (`/tasks`) — минимальный, добавлен по отдельному запросу
  ("нужен простой список тасков, управляемый через MCP").
- Деплой — Спринтхост (SSH+MySQL, PHP 8.5), домен технический (`xsph.ru`
  поддомен), SSL пока не настроен → веб-форма Claude "Add custom connector"
  не работает (требует HTTPS), рабочий канал — Claude Code CLI по `http://`.
