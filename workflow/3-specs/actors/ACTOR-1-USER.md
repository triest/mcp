# ACTOR-1-USER-IN-TASKTRACKER

RA-код: `RA-TASKS-ACTOR-USER`

## Кто это

Зарегистрированный человек-пользователь веб-интерфейса (`/tasks`). Аутентифицируется через Laravel Sanctum (`access_token`), полученный по `/api/auth/register` или `/api/auth/login`.

## Что может

- Создавать, читать, обновлять, удалять задачи (свои и общие — плоский список без разграничения по проектам, см. известные ограничения в `../../../README.md`).
- Менять статус задачи.
- Назначать задачу исполнителю (другому пользователю, становясь `ACTOR-2-ASSIGNEE`).
- Выпускать и отзывать собственные MCP-токены (`/api/mcp-tokens`).
